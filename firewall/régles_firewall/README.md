# Règles Firewall

Ce dossier contiendra les règles configurées sur pfSense.

## Objectifs

- Autoriser le LAN vers Internet.
- Autoriser les flux nécessaires entre LAN et DMZ.
- Limiter les accès de la DMZ vers le LAN.
- Autoriser uniquement les services nécessaires.
- Documenter les règles et les tests réalisés.
