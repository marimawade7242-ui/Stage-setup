# Configuration VPN

Ce dossier servira à documenter la configuration du VPN du laboratoire.

## Solution prévue

Le VPN choisi sera WireGuard ou OpenVPN.

## Objectif

Permettre un accès distant sécurisé au laboratoire virtuel, tout en gardant
les expérimentations confinées au réseau de test.
